#### Beschreibung:

Das Auto Suggest gibt unterhalb eines Suchfenster eine Vorschau auf alle möglichen Suchbegriffe.

#### Verwendung:

Vorrangig wird das Auto Suggest bei langen Auswahllisten wie bei der Studioauswahl verwendet,
um die Eingabe dem Nutzenden so einfach wie möglich zu machen

#### Verhalten:

Sobald eine Eingabe in das Inputfeld gemacht wird, öffnet sich die Vorschlagsliste (default=alphabethisch),
die sich den Eingaben im Inputfeld anpasst. Wenn die Eingabe gelöscht wird, wird die Vorschlagsliste wieder ausgeblendet.
